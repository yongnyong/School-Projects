# 5G to 6G Network Evolution

5G 통신 인프라의 핵심 기술과 한계를 분석하고, 6G 네트워크가 어떤 방향으로 발전하는지 정리한 네트워크 기술 조사 프로젝트입니다.

이 프로젝트는 5G의 OFDM, Beamforming, Massive MIMO, mmWave 구조를 바탕으로 6G의 AI-Native 네트워크, Cell-Free Massive MIMO, THz 통신, 저궤도 위성 통신, 초저지연 서비스 확장 가능성을 비교 분석했습니다.

## Key Topics

### 1. Mobile Network Generation Comparison

3G, 4G, 5G, 6G를 표준 시기, 상용화 시기, 주파수, 대역폭, 데이터 속도, 핵심 기술 기준으로 비교했습니다.

### 2. 5G Core Technologies

- OFDM: 넓은 주파수 대역을 직교 서브캐리어로 나누어 전송하는 방식
- Beamforming: 특정 사용자 방향으로 신호를 집중해 전송 효율을 높이는 기술
- Massive MIMO: 다수 안테나를 활용해 통신 품질과 용량을 높이는 기술
- mmWave: 초고속 전송을 가능하게 하지만 짧은 커버리지를 가지는 고주파 대역

### 3. 5G Limitations

5G는 높은 전송 속도와 낮은 지연을 제공하지만, mmWave 커버리지 문제, Massive MIMO 최적화 난이도, XR/자율주행 등 미래 서비스의 초저지연 요구를 완전히 충족하기 어렵다는 한계가 있습니다.

### 4. 6G Direction

6G는 단순한 속도 향상이 아니라 AI 기반 자율 최적화, Cell-Free 구조, THz 기반 초고속 통신, 지상-비지상 네트워크 통합을 통해 산업 전반의 통신 패러다임을 바꾸는 플랫폼으로 제시했습니다.

### 5. Industry Use Cases

- Tesla: V2X, 군집주행, 엣지 노드 차량
- Samsung: XR, 웨어러블, 고정밀 클라우드 렌더링
- Amazon: 드론 배송, 로봇 자동화, AI 물류 네트워크

## What I Learned

- 이동통신 세대 변화는 단순한 속도 향상이 아니라 네트워크 구조와 서비스 요구의 변화라는 점을 이해했습니다.
- 5G의 핵심 기술이 6G에서 어떻게 확장되는지 기술 흐름을 비교하는 관점을 익혔습니다.
- AI-Native 네트워크가 기존 사람 중심 운영 방식에서 자율·지능형 네트워크로 변화하는 핵심 개념임을 정리했습니다.
- 팀장으로서 발표 구조를 설계하고, 자료조사와 시각화 방향을 조율하는 경험을 했습니다.
